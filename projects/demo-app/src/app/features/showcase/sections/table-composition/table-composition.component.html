Table Composition Breakdown:

  1. Selection column (checkboxes) for bulk selection.
  2. Global actions / toolbar for bulk operations.
  3. Sortable headers with indicators and keyboard support.
  4. Per-row action menu (kebab) for row-specific commands.
  5. Grouped / expandable rows for hierarchical data.
  6. Tooltips for truncated content and extra metadata.
  7. Column resize / reflow affordance and drag handles.
