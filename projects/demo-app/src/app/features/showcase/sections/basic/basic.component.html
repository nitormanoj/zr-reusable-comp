Table container composition

High-level parts that make up the table container and common UX affordances.

  1. Selection column — optional checkbox column for selecting rows.
  2. Global actions — toolbar or kebab with bulk actions for the table.
  3. Sortable headers — column headers with sort indicators and keyboard support.
  4. Row actions — per-row action menu (edit, delete, more).
  5. Row grouping / expansion — tree-like groups or expandable details rows.
  6. Tooltips — hover tooltips for truncated or extra info.
  7. Column resize / reflow — adjustable column widths and responsive layout.

Table Composition Breakdown:

Each numbered item above maps to an area in the table UI. Use column templates, header templates, and row templates to implement these affordances with `ui-table`.
